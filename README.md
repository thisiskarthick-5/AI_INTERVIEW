# VANTAGE AI | Master Your Interview

![VANTAGE AI Banner](https://images.unsplash.com/photo-1486406146926-c627a92ad1ab?q=80&w=2070&auto=format&fit=crop)

VANTAGE AI is an AI-powered interview coaching platform designed to help students and job seekers prepare for high-stakes interviews. Built with React and Tailwind CSS v4, it provides a realistic environment for candidates to practice, receive instant feedback, and land their dream jobs.

## 🚀 Key Features

- **Voice Analysis**: Evaluations of tone, pace, and filler word usage to ensure clear and authoritative delivery.
- **Cognitive Logic**: Deep analysis of problem-solving approaches for both technical and behavioral interview rounds.
- **Instant Feedback**: Comprehensive performance reports with actionable improvement tips generated immediately after each session.
- **Mock Simulations**: Realistic interview scenarios tailored to specific domains like Software Engineering, Finance, and Product Management.
- **Privacy First**: 100% private practice sessions with secure data handling.

## 🛠 Tech Stack

- **Frontend**: React 19 (Vite)
- **Styling**: Tailwind CSS v4 (PostCSS)
- **Animation**: CSS Keyframes & React State Hooks
- **Design System**: Glassmorphism & Professional Neural Aesthetic
- **Fonts**: Oswald (Headers), Inter (Body)

## 📦 Installation

To get the project running locally:

1. **Clone the repository**:
   ```bash
   git clone [your-repo-url]
   cd aiinterview
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
